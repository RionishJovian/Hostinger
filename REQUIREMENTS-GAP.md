## Classification

- ✅ Implemented and verified — implemented in Build 21 and covered by local automated verification.
- 🟡 Implemented but needs real-device/external acceptance — code or durable records exist, but the required RouterOS, vendor, infrastructure, browser, push, or field evidence does not.
- ❌ Missing — no adequate v1 implementation exists.
- ⚠️ Conflicting or legacy behavior — Build 21 behavior conflicts with frozen v1 or is outside the frozen scope; preserve data and working code until a safe migration/removal decision is implemented.
